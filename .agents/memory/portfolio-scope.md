name: Portfolio scope
description: Hosting and scope constraints for future portfolio work.
---

The portfolio is deployed from GitHub to Netlify. Do not add a backend, database, authentication, or a Replit deployment.

**Why:** The user explicitly specified the existing hosting and prohibited those additions.

**How to apply:** Keep work within the existing static frontend and preserve Netlify compatibility.

For the redesign, the user explicitly requested preserving existing content and section order, a deep navy (#07101f) base with blue accents, and only Motion and Lenis as added libraries—no Three.js, video backgrounds, or heavy libraries.

**Why:** The user wants a distinctive portfolio without changing its content or adding heavy dependencies.

**How to apply:** Keep future refinements consistent with this scope unless the user changes it. All movement must respect reduced-motion preferences.
